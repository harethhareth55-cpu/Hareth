# Badge

A small pill naming the state of an order, debt or stock line.

Every state is a word as well as a colour, so a colour-blind cashier reads the same thing. The default badge is green (ok); add `new` (blue), `warn` (amber), `bad` (red) or `off` (grey).

Delivery order states map as: جديد `new`, مع المندوب `warn`, سُلّمت `ok`, مرتجع `bad`, ملغى `off`.

# Card

The white panel that holds a form, a list or a block of figures.

Cards are the only element with both a fill and a shadow (`surface`, `shadow-card`, `radius-lg`, 16px padding). Start a card with an `.eyebrow` or an `h3` in `section` style when it needs a heading.

Do not nest cards. Inside a card, separate groups with `line` hairlines (`.kv`, table rows), not with more cards.

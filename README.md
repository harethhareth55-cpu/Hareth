# محاسب الكاشير (Delivery / Store Cashier App)

تطبيق ويب بسيط لكاشير أي محل: يخزّن قائمة البضائع (باركود + اسم + سعر)، ومع كل عملية بيع
تفحص باركود كل سلعة (بالكاميرا أو بماسح باركود USB/بلوتوث) فيضاف سعرها تلقائيًا لفاتورة
الزبون، وبالنهاية يطلع المجموع الكلي، وتقدر تصدّر كل شي كملف إكسل.

يشتغل من المتصفح مباشرة (موبايل أو كمبيوتر) بدون تثبيت أو سيرفر — كل البيانات تُخزَّن
على نفس الجهاز.

## طريقة التشغيل

1. افتح ملف `index.html` مباشرة بالمتصفح، أو شغّل سيرفر بسيط بمجلد المشروع:
   ```
   python3 -m http.server 8000
   ```
   وافتح `http://localhost:8000` من المتصفح.
2. لازم يكون عندك اتصال إنترنت أول مرة (لتحميل مكتبتي القراءة/الكتابة بالإكسل ومسح
   الباركود من CDN). بعدها المتصفح يخزّنهم بالكاش.

## الاستخدام

### 1. إضافة البضائع
من تبويب **المنتجات**:
- أضف كل صنف يدويًا (باركود، اسم، سعر)، أو
- استورد قائمة جاهزة من ملف إكسل بزر **استيراد من إكسل** (الأعمدة المتوقعة: باركود،
  اسم، سعر — بأي ترتيب، عربي أو إنكليزي).

### 2. البيع
من تبويب **البيع**:
- **إدخال يدوي / ماسح USB**: الحقل بالأعلى يستقبل تلقائيًا أي ماسح باركود متصل
  بالكمبيوتر (يعمل مثل لوحة مفاتيح)، أو اكتب الكود يدويًا واضغط Enter.
- **كاميرا الموبايل**: بدّل للوضع التاني لتشغيل كاميرا الموبايل ومسح الباركود مباشرة
  (يحتاج إذن كاميرا من المتصفح).
- إذا الكود مو مسجل، بيفتح مربع لإضافة المنتج فورًا (اسم + سعر) وبعدها يضاف للفاتورة
  ويُحفظ بقائمة المنتجات تلقائيًا.
- تقدر تعدّل الكمية أو تحذف أي صنف من السلة.
- زر **إنهاء البيع** يقفل الفاتورة، يحسب المجموع، ويسجلها بالتقارير.

### 3. التقارير والإكسل
من تبويب **التقارير**:
- تصدير مبيعات اليوم أو كل المبيعات كملف إكسل (فيه صفحة ملخص فواتير + صفحة تفاصيل
  كل صنف).
- بعد إنهاء أي فاتورة تقدر تصدّرها لحالها فورًا من نافذة التأكيد.

### 4. الإعدادات
اسم المحل (يظهر برأس تقرير الإكسل) ورمز العملة (افتراضيًا د.ع).

## ملاحظات تقنية

- كل البيانات (منتجات، فواتير، إعدادات) تُخزَّن بـ `localStorage` بنفس المتصفح/الجهاز —
  لو مسحت بيانات المتصفح أو غيرت جهاز تضيع، فيفضل تصدّر نسخة إكسل احتياطية بين فترة
  وفترة من زر **تصدير المنتجات** و**تصدير كل المبيعات**.
- المكتبات المستخدمة: [SheetJS (xlsx)](https://sheetjs.com) لقراءة/كتابة إكسل،
  و[html5-qrcode](https://github.com/mebjas/html5-qrcode) لمسح الباركود بالكاميرا.
- ما فيه سيرفر أو قاعدة بيانات خارجية — التطبيق يشتغل بالكامل داخل المتصفح.

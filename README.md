# محاسب الكاشير (Delivery / Store Cashier App)

تطبيق ويب لكاشير أي محل: يخزّن قائمة البضائع (باركود + اسم + سعر) على **قاعدة بيانات
سحابية (Firebase)**، ومع كل عملية بيع تفحص باركود كل سلعة (بالكاميرا أو بماسح باركود
USB/بلوتوث) فيضاف سعرها تلقائيًا لفاتورة الزبون، وبالنهاية يطلع المجموع الكلي، وتقدر
تصدّر كل شي كملف إكسل.

كل محل يسجّل حساب خاص فيه، وبيانات المحل (منتجات + فواتير) تتزامن **فورًا** بين كل
الأجهزة/الكاشيرات المسجلين بنفس المحل — ما تضيع البيانات لو تغيّر الجهاز أو انمسح
المتصفح.

التطبيق يُدار **باشتراك شهري/سنوي**: كل محل جديد ياخذ فترة تجربة مجانية، وبعدها لازم
يفعّل اشتراك عن طريق التحويل (ZainCash / ماستر كارد الرافدين / FIB) وإرسال رقم العملية
من داخل التطبيق — وأنت توافق عليه يدويًا من **لوحة إدارة منفصلة** (`admin.html`).

## إعداد Firebase (خطوة لازمة أول مرة بس)

التطبيق يحتاج مشروع Firebase مجاني تربطه فيه. الخطوات:

1. افتح [console.firebase.google.com](https://console.firebase.google.com) وسجّل
   دخول بحساب Google.
2. **Add project** > اكتب اسم أي شي > تقدر تعطّل Google Analytics > Create project.
3. من القائمة الجانبية: **Build → Authentication → Get started** > فعّل طريقة
   **Email/Password**.
4. من القائمة الجانبية: **Build → Firestore Database → Create database** > اختر أقرب
   موقع سيرفر > ابدأ بوضع **production mode**.
5. روح لتبويب **Rules** داخل Firestore، امسح المحتوى الموجود، والصق مكانه محتوى ملف
   `firestore.rules` الموجود بهذا المشروع، واضغط **Publish**.
6. رجع لصفحة إعدادات المشروع (⚙️ بالأعلى) > **Project settings** > بالأسفل "Your apps"
   > اضغط أيقونة الويب `</>` > سمّي التطبيق أي اسم > **Register app** (بدون تفعيل
   Hosting).
7. راح يطلع كود فيه `firebaseConfig = {...}` — انسخ القيم (apiKey, authDomain,
   projectId...) والصقها بملف `js/firebase-config.js` مكان النصوص
   "ضع-هنا-..." داخل نفس الملف.
8. احفظ الملف. التطبيق جاهز.

## طريقة التشغيل

1. افتح ملف `index.html` مباشرة بالمتصفح، أو شغّل سيرفر بسيط بمجلد المشروع:
   ```
   python3 -m http.server 8000
   ```
   وافتح `http://localhost:8000` من المتصفح.
2. لازم اتصال إنترنت دائمًا (يحمّل مكتبات الإكسل/الباركود/Firebase من CDN، ويحتاج نت
   عشان يحفظ ويزامن البيانات مع Firestore).

## الاستخدام

### 0. الحساب والمحل
- **أول مرة**: من شاشة الدخول اختر تبويب **"محل جديد"** > اكتب اسم المحل + بريد +
  كلمة مرور > يسجّلك تلقائيًا كمالك المحل.
- **لإضافة كاشير ثاني** (جهاز/حساب ثاني بنفس المحل): من تبويب **الإعدادات** انسخ
  **"كود المحل"** وأعطه لصاحب الجهاز التاني. هو يفتح التطبيق، يختار تبويب
  **"الانضمام لمحل"**، ويحط الكود + بريده وكلمة مروره الخاصة.
- بعدها أي بيع أو تعديل منتج بأي جهاز يظهر فورًا بباقي الأجهزة.

### 1. إضافة البضائع
من تبويب **المنتجات**:
- أضف كل صنف يدويًا (باركود، اسم، سعر)، أو
- استورد قائمة جاهزة من ملف إكسل بزر **استيراد من إكسل** (الأعمدة المتوقعة: باركود،
  اسم، سعر — بأي ترتيب، عربي أو إنكليزي).

### 2. البيع
من تبويب **البيع**:
- **إدخال يدوي / ماسح USB**: الحقل بالأعلى يستقبل تلقائيًا أي ماسح باركود متصل
  بالكمبيوتر (يعمل مثل لوحة مفاتيح)، أو اكتب الكود يدويًا واضغط Enter.
- **كاميرا الموبايل**: بدّل للوضع التاني لتشغيل كاميرا الموبايل ومسح الباركود مباشرة
  (يحتاج إذن كاميرا من المتصفح).
- إذا الكود مو مسجل، بيفتح مربع لإضافة المنتج فورًا (اسم + سعر) وبعدها يضاف للفاتورة
  ويُحفظ بقائمة المنتجات تلقائيًا.
- تقدر تعدّل الكمية أو تحذف أي صنف من السلة.
- زر **إنهاء البيع** يقفل الفاتورة، يحسب المجموع، ويسجلها بالتقارير.

### 3. التقارير والإكسل
من تبويب **التقارير**:
- تصدير مبيعات اليوم أو كل المبيعات كملف إكسل (فيه صفحة ملخص فواتير + صفحة تفاصيل
  كل صنف).
- بعد إنهاء أي فاتورة تقدر تصدّرها لحالها فورًا من نافذة التأكيد.

### 4. الإعدادات
اسم المحل (يظهر برأس تقرير الإكسل)، رمز العملة (افتراضيًا د.ع)، كود المحل (لإضافة
كاشيرات)، وزر تسجيل الخروج.

### 5. الاشتراك
- أي محل جديد يسجّل **يضل بانتظار مراجعتك** — ما يدخل التطبيق مباشرة، تشوفه بلوحة
  الإدارة وتوافق عليه (أو ترفضه) بنفسك أول.
- فور ما توافق، ياخذ المحل **تجربة مجانية ١٤ يوم** تلقائيًا (تبدأ من لحظة الموافقة،
  مو من لحظة التسجيل). عدد الأيام معرّف بثابت `TRIAL_DAYS` بملف `js/admin.js`.
- بعد انتهاء التجربة (أو الاشتراك)، التطبيق **يقفل نفسه تلقائيًا** ويحصر المستخدم
  بشاشة "الاشتراك" لين يفعّل اشتراك جديد.
- بشاشة الاشتراك يختار المستخدم خطة **شهري (٨٠$) أو سنوي (٥٠٠$)**، يحوّل الفلوس
  بأي طريقة من الطرق المعروضة، ويدخل رقم العملية. الطلب يروح **لوحة الإدارة**
  بانتظار موافقتك.
- الأسعار معرّفة بأعلى ملف `js/app.js` بثابت `PLANS`، وأرقام استلام الدفع بثابت
  `PAYMENT_INFO` بنفس الملف — عدّلها لو تغيّرت.

## لوحة إدارة الاشتراكات (admin.html)

صفحة منفصلة (`admin.html`) مخصصة لك أنت بس (صاحب التطبيق)، ما تظهر ولا ترتبط بأي محل:

- افتحها وسجّل دخول (أول مرة تسجّل حساب تلقائيًا) ببريدك المحدد بملف
  `firestore.rules` (الدالة `isAdmin`) — حاليًا `harethhareth55@gmail.com`. لو
  تغيّر بريدك، لازم تعدّله بمكانين: `firestore.rules` و`js/admin.js`
  (الثابت `ADMIN_EMAIL`)، وتعيد نشر القواعد بلوحة Firebase.
- **محلات جديدة بانتظار الموافقة**: أول جدول بالصفحة — توافق فيفتح عندهم التطبيق
  فورًا ببدء التجربة المجانية، أو ترفض.
- **طلبات دفع بانتظار المراجعة**: اسم المحل، الخطة، المبلغ، الطريقة، رقم العملية —
  تتأكد إن الفلوس فعلاً وصلتك (تفتح تطبيق ZainCash أو حساب البنك وتتحقق يدويًا)،
  وبعدها تضغط **قبول** فيفعّل اشتراك المحل تلقائيًا، أو **رفض** لو الطلب غير صحيح.
- **كل المحلات**: جدول بكل المحلات وحالة اشتراك كل وحد منهم.
- الحماية حقيقية على مستوى قاعدة البيانات (مو بس بالواجهة) — حتى لو حد عرف رابط
  الصفحة أو عدّل الكود من متصفحه، ما يقدر يوافق على تسجيل محل أو طلب دفع، ولا حتى
  يفعّل اشتراك محله بنفسه، إلا لو دخل بنفس بريدك المحدد بالقواعد.

## ملاحظات تقنية

- البيانات (منتجات، فواتير، اسم المحل) تُخزَّن بقاعدة بيانات **Firestore** السحابية
  وتتزامن فورًا (Realtime) بين كل الأجهزة المسجّلة بنفس المحل. سلة الفاتورة الحالية
  (قبل الضغط على "إنهاء البيع") محلية بس بالجهاز، ما تتزامن.
- كل محل معزول تمامًا عن باقي المحلات (كل واحد يشوف بياناته بس)، عبر قواعد الحماية
  بملف `firestore.rules`.
- "كود المحل" هو نفسه معرّف مستند المحل بقاعدة البيانات — أي شخص يعرفه يقدر ينضم
  كـكاشير، فلا تشاركه إلا مع موظفينك.
- المكتبات المستخدمة: [Firebase](https://firebase.google.com) (تسجيل الدخول +
  قاعدة البيانات)، [SheetJS (xlsx)](https://sheetjs.com) لقراءة/كتابة إكسل،
  و[html5-qrcode](https://github.com/mebjas/html5-qrcode) لمسح الباركود بالكاميرا.

## هيكل الملفات

```
index.html            الصفحة الرئيسية وكل الشاشات (بما فيها شاشة الدخول والاشتراك)
admin.html            لوحة إدارة الاشتراكات (لك أنت بس)
css/style.css         التنسيق (مشترك بين الصفحتين)
js/firebase-config.js إعدادات مشروع Firebase (تعدّلها بمعلومات مشروعك)
js/app.js             كل منطق التطبيق (دخول/تسجيل، مخزن، سلة، إكسل، مسح الباركود، الاشتراك)
js/admin.js           منطق لوحة الإدارة (مراجعة والموافقة على طلبات الدفع)
firestore.rules       قواعد حماية قاعدة البيانات (تُلصق بلوحة تحكم Firebase)
```
